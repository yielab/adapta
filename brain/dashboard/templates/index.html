🎓 LoRA Fine-Tuning - Personalize Your Agents

Train your agents with custom data to specialize their knowledge and behavior

🎯 Training Workflow
1. Select Agent
Choose agent to personalize
2. Upload Data
Provide conversation examples
3. Train
Monitor progress
4. Use
Access via API/OpenClaw
📄 Example Training Data Format (Click to expand)
Each line = one JSON object with "messages" array:
{"messages": [{"role": "user", "content": "What is Python?"}, {"role": "assistant", "content": "Python is a programming language."}]}
{"messages": [{"role": "user", "content": "Explain lists"}, {"role": "assistant", "content": "Lists store multiple items."}]}
💡 Save as .jsonl file
⚙️ Requirements
Deps: pip install -r requirements-training.txt
Hardware: GPU recommended (CPU works but slower)
Time: 5-30 min depending on data size
