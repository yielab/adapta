🎓 Models for Training (LoRA Fine-Tuning)

Download base models for training custom adapters with your data

💡 How to Download Training Models
Click "⬇️ Download Model" → Model downloads automatically from HuggingFace to the server
Watch progress → Real-time progress bar shows download status
Automatic install → Model is cached in HuggingFace directory
Ready to train → Use in Training tab to create custom adapters

What are Training Models?
These are unquantized HuggingFace models required for LoRA fine-tuning. They're different from inference models (GGUF/llama-cpp).

⚠️ Important: These models are large (7B = ~14GB, 13B = ~26GB). Download happens on the server, so make sure you have enough disk space!

📚 Technical Note
LoRA training requires unquantized HuggingFace models. If your agent uses a GGUF/llama-cpp model (for fast inference), you'll need to select a HuggingFace version below. The LoRA adapter created can later be used with any compatible model.

💡 Best Practice: If your agent's model appears at the top, use it—it's already installed. Otherwise, choose Llama-2-7b or Mistral-7B (most compatible with Drupal/code training).

⚠️ No trainable models available

💡 How Document Upload Works

1. Upload Documents

Upload text files, markdown, PDFs, or JSON files containing knowledge for your agent. The system will automatically chunk and embed the content.

2. Semantic Search

Documents are split into chunks and embedded using sentence transformers. When you query the agent, relevant chunks are retrieved and added to the context.

3. Enhanced Responses

Your agent will use the uploaded documents to provide more accurate and detailed responses. Enable RAG when chatting to use document knowledge.

📝 Example Use Cases

  • Product documentation for customer support agents
  • Company policies and procedures
  • Technical manuals and guides
  • Research papers and articles
  • FAQ documents
