# Changelog

Everything that shipped, newest first, lives in **`CHANGELOG.md`** at the repository root. A roadmap
block moves there, verbatim with its closing notes, in the commit that closes it — so the roadmap holds
only open work and the changelog holds only shipped work.

[:material-github: View the changelog (CHANGELOG.md) on GitHub](https://github.com/yielab/adapta/blob/main/CHANGELOG.md){ .md-button .md-button--primary }

!!! note "Why it isn't embedded here"
    Like the roadmap, the changelog links to source paths (`adapta/…`, `tests/…`) that only resolve
    in-repo; embedding it would break those links under the site's strict build.
